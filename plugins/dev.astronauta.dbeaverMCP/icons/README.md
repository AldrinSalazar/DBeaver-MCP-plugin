The GitHub mark is `mark-github-16.svg` from GitHub's
[@primer/octicons 19.38.0](https://github.com/primer/octicons), distributed under
the included MIT license.

`github.svg` is the original source. The PNGs are rendered at 16 and 32 pixels
for normal and high DPI displays. `github-light` uses a white fill for dark
themes; the preferences page selects the variant from its foreground color.
